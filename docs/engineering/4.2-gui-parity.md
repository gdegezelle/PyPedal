# PyPedal 4.2 GUI parity matrix

Engineering inventory for replacing the temporary CustomTkinter desktop
with a PySide6 application. This file is not part of the user manual and
is not in MkDocs navigation.

PyPedal 4.2-A creates the Qt-free `PyPedal.application` layer. It does
**not** implement PySide6. CustomTkinter remains the development GUI
until later workstreams.

Preferred 4.2-E compatibility option: keep `PyPedal.pyp_app` as a thin
launcher that delegates to `PyPedal.desktop`, containing no CustomTkinter,
no tkinter, and no legacy UI implementation. Removing that import path
requires explicit evidence that the break is acceptable.

## Intentionally not carried forward as CTk behaviour

| Item | Reason | Parity |
|---|---|---|
| 500-row animal/inbreeding preview cap | The 98k-row browse path needs a virtual table, not a truncated text dump | INTENTIONALLY REMOVE (replace with full table) |
| Recompute Meuwissen–Luo on every inbreeding-by-year click | Application cache + year projection | INTENTIONALLY REMOVE (replace with reuse) |
| CustomTkinter widgets, themes, and Tk threading | Replaced by PySide6 | INTENTIONALLY REMOVE |
| `pyp_app` as a full UI implementation | Prefer a thin 4.2-E launcher delegating to `PyPedal.desktop` | INTENTIONALLY REMOVE (implementation, not the import path) |

## Counts

- Current CTk features inventoried: **15**
- MUST retain/replace: **13** current features (launch through progress, excluding the two IMPROVE listings that still remain required capability)
- IMPROVE: animal listing, inbreeding summary, inbreeding-by-year (and several SHOULD items)
- INTENTIONALLY REMOVE: CTk widgets, preview caps as the browse mechanism, duplicate inbreeding runs for year grouping, full UI body of `pyp_app`
- SHOULD-scope missing: **8**
- Implemented in 4.2-A: session, load options, load service, table source, error mapping, year-projection helper, architecture tests
- Not implemented in 4.2-A: PySide6, analysis catalog, export, jobs/threads, settings, recent files

MUST vs IMPROVE on the current 15:

- MUST: launch, open, pedformat, separator, renumber, failed-load retention, metadata, Meuwissen–Luo inbreeding, Lacy founders, About, busy, progress (12)
- IMPROVE: animal listing, inbreeding summary, inbreeding by year (3)
- INTENTIONALLY REMOVE: none of the 15 capabilities; only the CTk *mechanism* of preview caps and duplicate ML runs

## Quiet load decision (4.2-A)

The CustomTkinter open path sets `messages="quiet"` and does **not** set
`pedigree_summary=0`. Because quiet already suppresses the verbose
metadata dump, that CTk behaviour is left unchanged.

`PedigreeOpenOptions` defaults to `messages="quiet"` **and**
`pedigree_summary=0`. That is the intended future PySide6 load
configuration. It is not applied retroactively to `pedigree_open_options`
in `pyp_app.py`.

## Dependency direction

```
PyPedal.desktop          # 4.2-B, does not exist yet
        ↓
PyPedal.application      # 4.2-A
        ↓
PyPedal scientific modules
```

Forbidden: scientific modules importing application or desktop;
application importing PySide6, tkinter, or customtkinter; application
objects holding Qt types.

`pyp_app.py` may import application helpers during the CTk transition.
Application must never import `pyp_app`.
