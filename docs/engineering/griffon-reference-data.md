# Canonical Griffon reference-data notes

This is a maintainer note for the checked-in Griffon Bruxellois sample.
It is not a registry adjudication and it is not a scientific algorithm
change.

## Confirmed merges (applied)

Two interlocked duplicate identities were merged in both canonical
files:

- OriginalID 37482 into 37481 (`Halastjörnu Brynfridur Borubratta`)
- OriginalID 54587 into 54586 (`Manticorns Big Boss`; the transfer-affix
  name on 54587 was removed with that duplicate record)

The surviving source records were kept. Parent references to the dropped
IDs were remapped. Record count is 97,999.

## Remaining candidate duplicate identities

The same audit identified 66 additional candidate duplicate-identity
pairs from pedigree and name patterns after excluding the two confirmed
pairs above.

They have **not** been merged. Each pair requires verification against
the original registry or import source. Name heuristics alone are
insufficient. The broader prefix-name group contains both likely
duplicates and genuinely different animals. Examples of the latter
include Amalia / Amalia S18421/97 and Aurora Starr / Aurora Starr sister.

Do not treat the 66 pairs as confirmed duplicates.
